# Lone-Wolf-IT-Forensics-Investigation

This project is an analysis on the Jim Cloudy's Lone Wolf 2018 case. This report examines images, documents, cloud storage, browser & search history, application & systems, and lastly ends off with a timeline reconstruction and a conclusive paragraph. 
In the findings we discovered Jim Cloudy's account creation, cloud storage use, weapon-related searchs, ideolgies, and plannings. 

How evidence was maintained?
- Timestamps
- Hashes
- File paths
